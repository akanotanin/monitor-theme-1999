# Monitor 1999

![Monitor 1999 主题首页预览](preview.png)

把 [ricebucket/komari-theme-1999](https://github.com/r1cebucket/komari-theme-1999)（基于原版 **v1.0.1**）移植到
[极简探针 Monitor](https://github.com/monitor-probe/monitor) 的主题。

## 主要功能

- **新粗野主义视觉**：粗边框、硬阴影、像素化的加载动画，强调色可选（黄 / 红 / 蓝 / 绿 / 紫）。
- **卡片 / 列表双视图**：访客的视图偏好记在本机，站点可在后台设置默认视图。
- **分组**：Hub 后台给节点设了分组后，首页顶部出现分组标签（全部 / 组名 / 未分组），点一下只看该组。列表视图按分组分段显示；卡片视图在后台三选一——只保留顶栏标签（默认）、「标签 + 分段标题」、或整行都不出现（`cardGroupView=none`）。节点都没设分组时整块不出现。原版只把 Hub 的 `group` 字段读进状态、没有呈现，这一项是移植版新增的。
- **卡片三网延迟 + 丢包率**：节点卡片底部按探测线路列出最新延迟与丢包率（最多 3 条，线路名取自 Hub 后台的探测任务名），丢包率与详情弹窗同一口径；点开卡片就能看同一批线路的完整曲线与统计。站点可在后台关掉（`showNodePing`），也可以用 `cardPingLines` 指定显示哪几条、按什么顺序（每行一个名字，留空=自动取有数据的前 3 条）。
- **节点卡片**：CPU、内存、磁盘、流量四条进度条；流量条下那一行是「上行合计 · 上行速率」与「下行合计 · 下行速率」。流量条按 Hub 的计费周期口径与 `sum` / `max` / `up` / `down` 模式绘制，未设流量上限时画成斜纹。运行时间不在卡片上（列表视图的行尾仍有，且强制显示、没有开关）。
- **成本卡片**（移植版新增，参照原仓库 `custom-body/cost.html` 的那两张卡，合成一张卡里的两栏）：分组标签下方一张汇总条，左边 **COST / MONTH**（按价格与付款周期折算出每月固定支出，与到期时间无关），右边 **RESIDUAL VALUE**（还剩多少没用掉的预付金额），最右边一行小字（在算的台数 / 剩余天数合计 / 用到的汇率 / 没摊进来的台数）。
  - 两个数据都来自节点在 Hub 后台填的**价格 / 货币 / 付款周期 / 到期时间**（`/api/nodes` 公开字段）。
  - 剩余天数直接用 Hub 算好的 `expires_in`（按 Hub 自己的日历），**不拿访客的时钟去减到期日**——Hub 源码的注释里写明了那样会在每个周期里有一段时间把所有节点显示成已过期。没填到期时间或已过期的节点不计入剩余价值，7 天内到期的做成红色印章、已过期的标 `EXPIRED`。
  - 付款周期按 月付 30 / 季付 90 / 半年 180 / 年付 365 / 两年 730 / 三年 1095 天折算；**「一次性」推不出成本，两栏都不计入**（小字里标 `N SKIPPED`），不拿 30 天之类的默认值硬凑数字。
  - 多货币按站点设置的**固定汇率**折算成结算货币（`costCurrency` / `costRates`，不联网取实时汇率：主题全离线，墙内访客请求外部汇率接口本来就会失败）；缺汇率的货币标「?」、不计入合计，控制台提示一次。
  - 节点一台都没填价格时整块不出现；两栏可分别关掉（`showCostCard` / `showCostMonthCard`，默认都开）。
- **节点详情**：硬件 / 系统 / 存储 / 网络 四块信息（CPU 型号与核心数、架构、虚拟化、系统、内核、运行时间、最近上报、内存 / 交换 / 磁盘用量、双向速率与累计流量、TCP/UDP 连接数）。
- **历史曲线**：CPU、内存、磁盘、网络四张图，窗口 1H / 6H / 24H / 3D / 7D（登录后的管理员多一个 30D）。
- **延迟区块**：按探测线路列出最新延迟、丢包率、MIN / AVG / MAX / P50 / P99，并画出延迟曲线。
- **小动效**：数字变化时的乱码翻牌、像素骨架；详情页支持 `Esc` 关闭与键盘操作。
- **离线可用**：字体与 ECharts 都打进主题包，不依赖第三方 CDN。

## 与原版的差异

- **新增分组**（见上）：补上筛选标签，列表视图按分组分段，卡片视图的分段由站点设置 `cardGroupView` 决定（`tabs` 默认只留标签 / `sections` 加分段标题 / `none` 连标签都不显示）。访客的筛选只作用于本次浏览，不写本机存储、也不改站点设置。
- **新增卡片三网延迟 + 丢包率**（见上）：上游主题只在详情弹窗里画延迟，卡片上没有。数据与详情弹窗同一个来源（`series=ping`），每张卡片 60 秒取一次、页面不可见时不取，站点可关。原版没有这块内容。
- **卡片底部那一栏拆掉了**（见上）：原版卡片最下面是一栏「UP SPEED / DOWN SPEED / UPTIME」三格。移植版把上行 / 下行速率并进 NETWORK 区（合计后跟速率，`↑ 1.6 GB · 21.7 KB/s`），运行时间不再上卡片（列表视图行尾仍有，恒显示、移除了原来的开关），空出来的底部给三网延迟 + 丢包率。上游那一栏的标记（`.node-footer` / `.footer-stat`）因此不再出现在卡片里。
- **新增成本卡片**（见上）：上游把「每月花多少钱 / 还剩多少没用掉」放在仓库的 `custom-body/cost.html` 里当可选片段（要自己贴进面板的自定义 body，且用 Frankfurter 取实时汇率），移植版把它做进主题本体、给两个后台开关，并合成一张卡里的两栏；汇率改为站点在后台填的固定表（主题全离线）。
- 数据改由极简探针的 REST / WebSocket 提供，不需要 Komari 服务器；站点信息与主题配置读 `/api/me` 与 `/api/themes/1999/config`。
- 移除原版有、极简探针不提供的部分：登录弹窗与 OAuth（登录在 `/admin`）、GPU 型号、进程数与连接数的历史曲线，以及匿名访客拿不到的 30 天历史窗口。
- 字体与 ECharts 改为包内本地资源（原版走 Google Fonts / jsDelivr，中国大陆不可达）。

## 安装

首次安装需从 Releases 下载 theme.tar.gz 上传至探针后台，后续可在主题卡片上点击从 GitHub 更新。
