# Monitor 1999

![Monitor 1999 主题首页预览](preview.png?v=2)

把 [ricebucket/komari-theme-1999](https://github.com/r1cebucket/komari-theme-1999)（基于原版 **v1.0.1**）移植到
[极简探针 Monitor](https://github.com/monitor-probe/monitor) 的主题。纯静态前端，只读 hub 的公开接口，
字体与 ECharts 都打进包里，不依赖第三方 CDN。

## 主要功能

- **卡片 / 列表双视图**：访客的视图偏好记在本机，站点可在后台设默认视图。
- **分组筛选**：Hub 后台给节点设了分组后出现「全部 / 组名 / 未分组」标签，点一下只看该组（移植版新增）。
- **节点卡片**：CPU、内存、磁盘、流量四条进度条；流量条下是「上行合计 · 上行速率」与「下行合计 · 下行速率」。
- **三网延迟**：卡片底部按探测线路列出最新延迟与丢包率（默认三列并排），点开卡片看同一批线路的完整曲线与统计（MIN / AVG / MAX / P50 / P99）（移植版新增）。
- **成本卡片**：左栏每月固定支出、右栏还没用掉的预付金额，下方是到期印章与口径小字（移植版新增，算法见下）。
- **节点备注**：详情页里显示 Hub 后台按节点填的备注（公开备注访客可见；私有备注仅管理员可见、多一枚小锁图标），逗号分隔＝多枚。站点可在后台关掉。
- **节点详情**：硬件 / 系统 / 存储 / 网络 四块信息（CPU 型号与核心数、架构、虚拟化、系统、内核、运行时间、最近上报、内存 / 交换 / 磁盘用量、双向速率与累计流量、TCP / UDP 连接数）。
- **历史曲线**：CPU、内存、磁盘、网络四张图，窗口 1H / 6H / 24H / 3D / 7D（管理员多一个 30D）。
- **视觉与动效**：新粗野主义的粗边框、硬阴影、像素骨架；数字变化时的乱码翻牌；详情页支持 `Esc` 关闭与键盘操作。

## 成本卡片怎么算

- 数据来自 Hub 后台给每台节点填的**价格 / 货币 / 付款周期 / 到期时间**（`/api/nodes` 公开字段）。
- 付款周期按 月付 30 / 季付 90 / 半年 180 / 年付 365 / 两年 730 / 三年 1095 天折算；**「一次性」推不出成本，两栏都不计入**（小字里标 `N SKIPPED`）。
- 剩余天数用 Hub 算好的 `expires_in`，**不拿访客的时钟去减到期日**。没填到期时间或已过期的节点不计入剩余价值；7 天内到期的做成红色印章（文案 `TODAY / ND / EXPIRED`），宽屏逐台列出、窄屏收成可点开的汇总。
- 多货币折算分两层：**内置参考汇率**（带日期与来源的快照）打底，后台「汇率表」填的**优先覆盖**同名币种。访客端**不联网**取实时汇率（主题是离线静态包），用内置值折出来的标签会在悬停提示里自报日期与来源、`RATE` 那一行打 `*`；两张表里都没有的币种不进标签行，改在大数字下面用虚线框写「未计入 …」——大数字本身不含这部分钱，写出来才不会把合计说多。
- 节点一台都没填价格时整块不出现；两栏可分别关掉（见「主题设置」）。

## 与原版的差异

- **新增**：分组筛选、卡片三网延迟与丢包率、成本卡片、详情页节点备注。
- **拆掉卡片底部那一栏**：上游的「UP SPEED / DOWN SPEED / UPTIME」三格——上下行速率并进 NETWORK 区（合计后跟速率），运行时间不再上卡片（列表视图行尾仍有），空出来的底部给三网延迟。
- **卡片上的节点名收成一行**：超出用省略号，悬停与详情页看全名；上游名字多长就占多少行，同一行里名字短的卡片于是整体错位。
- **成本卡片改为内置汇率**：上游把它放在仓库的 `custom-body/cost.html` 里当可选片段（要自己贴进面板的自定义 body，且用 Frankfurter 取实时汇率），移植版做进主题本体并给了后台开关。
- **数据来源**：改用极简探针的 REST / WebSocket，不需要 Komari 服务器。
- **移除上游有、Monitor 没有的**：登录弹窗与 OAuth（登录在 `/admin`）、GPU 型号、进程数与连接数的历史曲线、匿名访客拿不到的 30 天历史窗口。
- **资源本地化**：字体与 ECharts 改为包内本地资源（上游走 Google Fonts / jsDelivr，中国大陆不可达）。

## 安装

首次安装需从 Releases 下载 theme.tar.gz 上传至探针后台，后续可在主题卡片上点击从 GitHub 更新。

## 主题设置

后台「主题 → 主题设置」，改完对访客立即生效：

| 分组 | 设置项 | 默认 | 说明 |
| --- | --- | --- | --- |
| 外观 | 强调色 | `yellow` | 页头与高亮区块的强调色（黄 / 红 / 蓝 / 绿 / 紫） |
| | 卡片边框风格 | `thick` | `thick` 粗边 / `thin` 细边 / `double` 双线 |
| 卡片与视图 | 默认视图 | `grid` | 访客首次打开首页时的视图；访客自己切过之后以访客为准 |
| | 卡片视图的分组展示 | `tabs` | `tabs` 只留顶栏标签 / `sections` 再加分段标题 / `none` 两个视图都不显示标签行；列表视图始终按分组分段 |
| | 卡片显示三网延迟 | 开 | 卡片底部显示探测线路的最新延迟与丢包率；关掉后访客页面不再请求延迟数据 |
| | 卡片显示哪几条探测线路 | 空 | 每行一个线路名（也可用逗号分隔），按填写顺序显示；留空 = 自动取有数据的前 3 条。名字要照抄 Hub 后台的探测任务名 |
| | 卡片延迟的排布 | `columns` | `columns` 三条线路并排成三列（卡片更矮）/ `rows` 每条线路占一行 |
| | 详情页显示节点备注 | 开 | 详情页里显示节点备注（Hub 后台按节点填的公开 / 私有备注，逗号分隔＝多枚）；关掉后这一块不渲染 |
| 成本卡片 | 显示每月成本 | 开 | 左栏 COST / MONTH：按价格与付款周期折算出的每月固定支出，与到期时间无关 |
| | 显示剩余价值 | 开 | 右栏 RESIDUAL VALUE：还没用掉的预付金额；关掉后这一栏与到期提醒都不显示 |
| | 结算货币 | `CNY` | 汇总用的货币，节点填的货币与它不同时按汇率折算（CNY / USD / EUR / GBP / JPY） |
| | 汇率表 | 空 | 留空 = 用主题内置的参考汇率；填了则同名币种覆盖内置值，每行 `货币=汇率`（例 `USD=7.2`） |
| 运行 | 数据刷新间隔 | `3` | 实时数据的刷新间隔，单位秒（建议 2-10） |
| | 显示后台入口按钮 | 开 | 未登录的访客是否显示顶栏的后台入口按钮（点击跳转 `/admin`） |
